Código de Huffman

Digite um texto e acompanhe a construção da árvore: a cada passo, o min-heap entrega os dois nós de menor frequência, que viram filhos de um nó novo com a soma. No fim, cada caminho da raiz até uma folha é o código da letra: 0 para a esquerda, 1 para a direita.

O laço que monta a árvore
/* uma folha por símbolo, ordenadas pela frequência */
for (int c = 0; c < 256; c++)
    if (freq[c]) inserir(novo(freq[c], c, NULL, NULL));

while (tam > 1) {
    No *a = extrair(), *b = extrair();      /* os dois menores */
    inserir(novo(a->freq + b->freq, 0, a, b)); /* o pai volta ao heap */
}
No *raiz = extrair();
# uma folha por símbolo, ordenadas pela frequência
heap = [(f, next(ordem), No(f, c)) for c, f in sorted(freq.items())]
heapq.heapify(heap)

while len(heap) > 1:
    fa, _, a = heapq.heappop(heap)          # os dois menores
    fb, _, b = heapq.heappop(heap)
    heapq.heappush(heap, (fa + fb, next(ordem), No(fa + fb, None, a, b)))
raiz = heap[0][2]

O menor sai à esquerda (bit 0) e o segundo menor à direita (bit 1). Empates são desfeitos pela ordem de criação dos nós, como no código do módulo.

A tupla (freq, ordem, nó) faz o heapq comparar primeiro a frequência e, nos empates, a ordem de criação. Assim o Python nunca precisa comparar dois objetos No.

Por que um heap

Os dois menores, sempre

A cada fusão é preciso achar os dois nós de menor frequência entre os que sobraram. Com um min-heap, cada extração e cada inserção custam O(log k); com uma lista sem ordem, cada busca custaria O(k).

Por que é ótimo

Os raros vão para o fundo

Cada fusão soma um bit ao código de todos os símbolos abaixo dela. Juntar sempre os dois menores pesos faz os bits extras caírem sobre os símbolos menos usados.

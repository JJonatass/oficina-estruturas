Busca Sequencial e Binária

Duas formas de achar um valor x num vetor. A sequencial olha as posições uma por uma e funciona em qualquer vetor. A binária compara x com o elemento do meio e descarta metade a cada passo, mas só dá a resposta certa se o vetor estiver ordenado. Rode as duas lado a lado no modo Corrida e compare os contadores de comparações.

As duas buscas em código
int busca_seq(const int v[], int n, int x) {
    for (int i = 0; i < n; i++)
        if (v[i] == x) return i;
    return -1;
}

int busca_bin(const int v[], int n, int x) {
    int ini = 0, fim = n - 1;
    while (ini <= fim) {
        int meio = ini + (fim - ini) / 2;
        if (v[meio] == x) return meio;
        if (v[meio] < x) ini = meio + 1;  /* descarta a esquerda */
        else             fim = meio - 1;  /* descarta a direita */
    }
    return -1;
}
def busca_seq(v, x):
    for i in range(len(v)):
        if v[i] == x:
            return i
    return -1

def busca_bin(v, x):
    ini, fim = 0, len(v) - 1
    while ini <= fim:
        meio = (ini + fim) // 2
        if v[meio] == x:
            return meio
        if v[meio] < x:
            ini = meio + 1   # descarta a esquerda
        else:
            fim = meio - 1   # descarta a direita
    return -1

Dobrar o vetor

+n contra +1

Com 15 elementos, a binária faz no máximo 4 comparações; com 31, 5; com 63, 6. Cada vez que o vetor dobra, ela ganha só uma comparação a mais, enquanto a sequencial dobra o trabalho.

O preço

Manter o vetor ordenado

Ordenar custa O(n log n) e inserir mantendo a ordem custa O(n). Para uma busca só, a sequencial sai mais barata; para muitas, ordenar uma vez e usar a binária compensa.

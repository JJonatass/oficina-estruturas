Lista Encadeada (Simples)

Uma lista encadeada é uma sequência de nós espalhados pela memória, cada um guardando um valor e um ponteiro para o próximo — não existe posição fixa nem acesso direto por índice como num array: para chegar ao décimo nó é preciso passar pelos nove anteriores. Em troca, inserir ou remover no início custa apenas trocar um ponteiro, O(1), não importa o tamanho da lista. Repare também numa pegadinha clássica: como cada nó só aponta para frente, remover do fim ainda exige percorrer tudo para achar o penúltimo nó — o preço de não ter uma lista duplamente encadeada.

Como isso é declarado
typedef struct No {
    int valor;        /* o dado guardado no nó */
    struct No *next;  /* endereço do próximo nó (NULL = fim da lista) */
} No;

No *head = NULL;      /* lista vazia: head não aponta para nada */
class No:
    def __init__(self, valor):
        self.valor = valor  # o dado guardado no nó
        self.next = None    # referência ao próximo nó (None = fim da lista)

head = None                 # lista vazia: head não aponta para nada

Cada nó guarda um valor e um ponteiro next para o nó seguinte; o último aponta para NULL. A lista toda é só o ponteiro head — quem perde o head perde a lista. Cada nó novo vem de um malloc(sizeof(No)).

Em Python não há malloc nem ponteiros explícitos: No(7) cria o nó e toda variável já é uma referência. None faz o papel de NULL, e o coletor de lixo libera o nó quando ninguém mais aponta para ele.

Como funciona a reversão

Reverter uma lista encadeada é o exercício clássico de ponteiros: três variáveis — prev, atual e próximo — caminham juntas pela lista, uma posição atrás da outra.

Lista encadeada

Nós espalhados pela memória, ligados por ponteiros. Inserir ou remover no início é O(1) — só muda um ponteiro. Acessar a posição i é O(n) — não existe atalho, é preciso caminhar nó a nó.

Array

Posições contíguas na memória. Acessar a posição i é O(1) — cálculo direto do endereço. Em compensação, inserir ou remover no início é O(n) — todo o resto precisa deslocar uma casa.

Início da lista

O(1)

Inserir ou remover a cabeça só exige trocar um ponteiro — a lista nem precisa saber o próprio tamanho.

Fim da lista (nesta variante)

Inserir O(1) · remover O(n)

Mantemos um ponteiro de cauda, então inserir no fim é rápido. Mas remover o último nó exige achar o penúltimo — e, sem ponteiro para trás, isso só se descobre percorrendo a lista inteira.

Implementação didática de uma lista encadeada simples (singly linked list), estrutura que remonta ao processamento de listas no fim dos anos 1950 — linguagens como IPL e Lisp. Complexidade O(1) para inserir/remover no início, O(n) para busca, acesso por posição e remoção no fim.

Trie Visual

Uma trie (árvore de prefixos) organiza um conjunto de palavras de um jeito bem diferente das árvores binárias de busca: cada aresta representa uma letra, e o caminho da raiz até um nó soletra um prefixo. Não existe rotação nem comparação de chaves inteiras — cada nó pode ter vários filhos (um por letra possível), e um nó é marcado quando o caminho até ele forma uma palavra completa. Use os controles abaixo para inserir, buscar, autocompletar e remover palavras.

Como a trie é construída

Cada nó representa uma letra (a raiz representa o prefixo vazio). Palavras que compartilham um começo compartilham também o mesmo caminho — é aí que mora a economia de uma trie. No exemplo abaixo, sol, sola e sopa dividem o prefixo so:

Removendo: desmarcar e podar

Remover uma palavra nunca é só "apagar um nó" — outras palavras podem depender do mesmo caminho:

1
Desmarcar o fim de palavraEncontramos o nó que corresponde à última letra e desligamos sua marca de "fim de palavra" — a palavra deixa de existir na trie.
2
Subir podando nós inúteisVoltamos pelo caminho, da última letra até a raiz: cada nó sem filhos e que não é fim de outra palavra é removido — ele só existia para sustentar a palavra que acabou de sair.
3
Parar ao encontrar uso compartilhadoAssim que um nó do caminho ainda tem outro filho, ou ainda é fim de outra palavra, a poda para ali — esse trecho do caminho continua servindo a outras palavras.
Qualquer operação

O(L), onde L é o tamanho da palavra

Inserir, buscar ou remover uma palavra custa um passo por letra — o tempo não depende de quantas palavras já estão guardadas na trie, ao contrário de uma árvore binária balanceada, onde o custo é O(log n) no número de chaves.

Autocompletar

Toda a subárvore de um prefixo

Como palavras com o mesmo prefixo compartilham o mesmo caminho, listar todas elas é só percorrer a subárvore abaixo do nó do prefixo — a base de qualquer campo de busca com sugestões.

Implementação didática de uma trie (árvore de prefixos), estrutura descrita por Axel Thue (1912) e formalizada por René de la Briandais (1959) e Edward Fredkin (1960), que cunhou o nome "trie" a partir de "retrieval". Complexidade: O(L) para busca, inserção e remoção, onde L é o comprimento da palavra.

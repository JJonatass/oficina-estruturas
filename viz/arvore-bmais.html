Árvore B+ Visual

Uma árvore B+ é uma árvore B que separa dois papéis: nós internos guardam só separadores para guiar a busca — cópias, nunca dados de verdade — e todo dado real mora nas folhas, sempre na mesma profundidade, encadeadas entre si numa lista ligada. O resultado: buscar um valor exato ainda é O(log n), mas varrer um intervalo inteiro de valores vira um simples passeio pela lista de folhas — sem nunca voltar à raiz. É por isso que é a estrutura real por trás da maioria dos índices de banco de dados.

Só as folhas guardam dados

Num nó interno, cada "chave" é só uma cópia usada para decidir para qual filho descer — o valor de verdade, se existir, está em alguma folha. Isso significa que todo valor é encontrado no mesmo nível de profundidade, e a árvore inteira pode ser varrida em ordem sem nenhuma recursão: basta achar a folha mais à esquerda e seguir os ponteiros next.

Removendo numa árvore B comum

Se a chave está num nó interno, ela precisa ser trocada pelo predecessor ou sucessor antes de ser removida de uma folha.

Removendo numa árvore B+

A chave só existe numa folha — a remoção desce direto até lá, sem troca nenhuma. Os separadores acima podem ficar desatualizados (são só cópias antigas), mas continuam funcionando como limites de roteamento: cada empréstimo ou fusão já corrige exatamente a fronteira que cruza.

Buscar um valor

O(log n) — desce até uma folha

Igual a qualquer árvore B: compara com os separadores e desce, sem nunca examinar dados nos nós internos.

Buscar um intervalo

O(log n + k) — desce uma vez, depois só anda

Desce até a folha onde o intervalo começa (O(log n)) e então segue os ponteiros entre folhas coletando os k valores do intervalo — sem tocar a árvore de novo. É exatamente o que um banco de dados faz numa consulta por faixa (WHERE idade BETWEEN 20 AND 30).

Implementação didática de uma árvore B+ com grau mínimo t = 2 (mesmos limites de chaves e filhos da árvore B clássica), com dados restritos às folhas e folhas encadeadas para varredura em ordem e consultas por intervalo. Complexidade: O(log n) para busca, inserção e remoção; O(log n + k) para um intervalo com k resultados.
